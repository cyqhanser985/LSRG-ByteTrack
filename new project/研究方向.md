### 一、 核心任务：开展“小型可观测性诊断实验” (Go/No-Go 判据)

在启动任何复杂的纠错动作（Reject / Resolve）之前，首先在已冻结的 $S_r$（活跃接管）事件池上，针对每个检测目标提取 **4 个计算开销极低、在线可观测的正交物理特征**：

1. **歧义裕度 (Margin Ambiguity)**
   $$m = top1 - top2$$
   *(反映当前局部关联的犹豫程度——即现有 DEN 信号)*

2. **运动突变 (Motion Surprise)**
   $$\Delta\theta = \angle(v_{\text{history}}, d_t - x_{t-1})$$
   *(反映检测位移方向与轨迹历史运动方向的夹角，或归一化的中心点残差)*

3. **遮挡系数 (Occlusion Coefficient)**
   $$Oc_i = \max_j \frac{|B_i \cap B_j|}{|B_i|}$$
   *(使用自交比 IoF 评估目标被其他边界框遮挡的物理程度，反映定位失真的风险)*

4. **结构交换不稳定性 (2×2 Swap Instability)**
   针对发生局部竞争的两个 Track ($T_1, T_2$) 与两个 Detection ($D_1, D_2$)，计算当前分配与交叉交换（Swap）分配之间的 Cost 差值。
   $$\Delta C_{\text{swap}} = (c_{12} + c_{21}) - (c_{11} + c_{22})$$

### 二、 路线决策判据 (Go / No-Go Decision)

根据上述诊断实验中，正交物理信号取并集（Union）后的召回率表现，决定项目的技术路线走向：

* **情况 A (继续 Gate 路线 - 演进为 `DEN-M`)**
  * **条件**：四者联合召回率 **$\ge 50\% \sim 60\%$**，且正常帧 FPR 维持在 $\le 1\% \sim 2\%$。
  * **动作**：证明在发生错误关联前存在足够的因果可观测信号。后续方案设计收敛为**“最小正交特征集”**（例如仅保留 Margin + Motion Surprise，裁剪其余复杂逻辑），并进入 Reject 模块开发。
* **情况 B (终止 Gate 路线 - 转向关联函数重构)**
  * **条件**：即使融合四种不同维度的廉价物理信号，联合召回率仍 **$< 40\%$**。
  * **动作**：尽早证伪 Gate-centric DEN 路线。不再继续堆叠门控参数，直接转向研究**“如何改善关联函数本身”**（如引入 OC-SORT 的观测中心运动补偿或 C-BIoU 的搜索空间自适应）。
