# 门控信号识别率汇总（导师汇报用）

> 依据《研究方向.md》的可观测性诊断实验（`diag_exp/`，2026-08-10）。口径：冻结 switch 事件池（4,756 条）为识别对象，C 组正常帧检测为负样本；**主口径（u2）为诊断最强的两个信号——Margin（几何裕度）与 Swap Instability（2×2 交换分配代价差，变体 B）——各自在成分级 FPR≤1% 预算下取最优阈值后以固定阈值取并**（并集 FPR 如实报告，约 1.1–1.3%，不再施加联合约束）；触发前置 = 共享资格（top1≥0.2 ∧ top2≥0.2）；识别率 = 并集捕获的事件占比（成分级 FPR≤2% 作敏感性）。事件按接管方历史分为三类：S_c 冷启动接管（1,841）、S_r 活跃接管（1,921）、S_h 历史重新激活（994）。

## 一、总体识别率（全部 switch 事件，n=4,756）

**四信号并集（Union 1∪2∪3∪4）：**

| 数据集 | 成分级 FPR≤1% | 成分级 FPR≤2% |
| :--- | :---: | :---: |
| MOT17（549 事件） | **19.7%** | 21.3% |
| MOT20（1,640 事件） | **39.8%** | 46.6% |
| SportsMOT（2,567 事件） | **14.1%** | 16.2% |
| **合并（4,756 事件）** | **23.5%** | 27.1% |

> 即：两信号各自在成分级误触发 ≤1% 预算下取最优阈值后取并（并集 FPR 合并口径 1.23%），全部 ID 切换事件中只有约 **1/4（23.5%）** 能在错误发生当帧被捕获；约 3/4 的事件发生时 margin 与 swap 两观测全部"正常"（与"自信而错"瓶颈一致）。

## 二、分类别识别率（四信号并集，FPR≤1%）

| 事件类别 | MOT17 | MOT20 | SportsMOT | 合并 |
| :--- | :---: | :---: | :---: | :---: |
| **S_c 冷启动接管**（n=1,841） | 12.2% | 44.9% | 2.8% | **9.6%** |
| **S_r 活跃接管**（n=1,921） | 22.9% | 37.0% | 39.3% | **35.7%** |
| **S_h 历史重新激活**（n=994） | 20.3% | 43.1% | 10.5% | **25.6%** |
| 全部 switch（n=4,756） | 19.7% | 39.8% | 14.1% | **23.5%** |

**敏感性（成分级 FPR≤2%）**：S_c 合并 10.4% / S_r 41.6% / S_h 29.9% / 全部 27.1%。

## 三、分特征识别率（合并口径，FPR≤1%）

| 特征 | S_c | S_r | S_h | 全部 |
| :--- | :---: | :---: | :---: | :---: |
| 1. Margin（top1−top2） | 9.5% | 24.5% | 24.2% | 18.6% |
| 2. Motion Surprise（v_obs_norm） | **不可定义**(0) | 14.7% | **不可定义**(0) | 6.0% |
| 3. Occlusion（同帧 IoF） | 1.0% | 6.1% | 4.5% | 3.8% |
| 4. Swap Instability（ΔC，D2=T2 自有检测） | 2.2% | **31.7%** | 8.1% | 15.3% |
| *敏感性：Swap 变体 A（D2=T1 自有检测）* | *12.0%* | *25.8%* | ***29.7%*** | *21.2%* |
| **u2：Margin ∪ Swap 固定阈值并集**（成分级 FPR≤1%） | **9.6%** | **35.7%** | **25.6%** | **23.5%** |
| *敏感性：u2 @成分级 FPR≤2%* | *10.4%* | *41.6%* | *29.9%* | *27.1%* |
| 对照：Union (1∪2∪3∪4) 联合搜索（整体 FPR≤1%） | 9.5% | 33.0% | 24.9% | 22.2% |

> "不可定义(0)"：S_c/S_h 的接管方在 F−1 无输出（定义使然），运动突变信号物理上不可计算——四正交特征对非 S_r 类别实际只有 3 个可用。

## 四、关键结构性发现

1. **类别可分性**：S_r（活跃接管）识别率最高（35.7%），S_h 次之（25.6%），**S_c（冷启动）最差（9.6%）**——SportsMOT 仅 2.8%（其 1,446 个冷启动事件中仅 43 个检测挂载到邻近活跃 track，top1/top2 结构缺失，门控结构性盲视，与"冷启动无历史预测"机理一致）。
2. **场景强依赖**：MOT20（拥挤场景）各类别识别率普遍最高（S_c 44.9% / S_h 43.1% / 全部 39.8%）；SportsMOT（高速稀疏）最低（全部 14.1%）。
3. **Swap 变体选择影响类别**：S_r 上"当前分配读法"（D2=T2 自有检测，变体 B）更强（31.7% vs 25.8%）；S_c/S_h 上变体 A（D2=T1 自有检测）更强（S_h 29.7% vs 8.1%；MOT20 的 S_c 58.8% vs 7.0%）——u2 主口径采用 S_r 上的更强变体（变体 B）。
4. **合格事件比例**（满足 top1≥0.2 ∧ top2≥0.2）：S_c 12.0%（221/1,841）、S_r 86.2%、S_h 46.8%、全部 49.2%——约一半 switch 事件在错误发生当帧不具备"竞争结构"，任何检测级门控在原理上无法捕获。

## 五、与 Go/No-Go 判据的衔接

双信号固定并集（u2）对 **S_r** 的识别率为 35.7%（成分级 FPR≤1%，并集 FPR 1.23%），全部 switch 事件为 23.5%——均低于情况 B（<40%）终止线或远低于情况 A（≥50–60%）继续线；仅在 MOT20 拥挤场景、放宽至成分级 FPR≤2% 时部分类别达到 44–51%（MOT20 全部 switch 46.6%；swap 变体 A 在 S_c/S_h 上个别类别达 50–56%）。**总体裁决不变：情况 B，终止 Gate 路线，转向关联函数重构**；拥挤场景（MOT20）的类别识别率差异提示：若未来做场景自适应门控，MOT20 类拥挤场景是唯一可能达到 50% 档位的场景，但跨场景泛化不成立。
