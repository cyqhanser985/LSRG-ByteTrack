## 1. 白布可视化口径定义

| 项 | 口径 |
|----|------|
| 白布 | 纯白图像 `np.full((h, w, 3), 255, np.uint8)`,**尺寸 = 该序列原图 WxH**(读首帧一次取得,之后不再读图),检测框坐标保持原图像素值,不缩放、不偏移,坐标保真 |
| 颜色 | 复用视频可视化的黄金角着色 `hue = (id × 137.5) mod 180`(HSV S=V=255):同 ID 恒定同色、相邻 ID 色差 ≥ 42.5°,与 `track_videos/*.mp4` 中的颜色完全一致,两套可视化可直接对照 |
| 描边 | **所有框带黑色描边**(先画 line_w+2 黑线,再画 line_w 彩线)——原因见 §3 对比度分析 |
| 标注 | 框 + 黑底白字数字 ID(与视频相同的标签条样式);`--no-label` 可只画框不标数字 |
| 帧范围 | 全序列 = track txt 的 min..max 帧(**含无检测间隙帧,空帧补齐**);事件窗口 = 事件帧 ±15 帧 |
| 帧率 | **30 fps(假设)**——序列无 fps 元数据,统一 30;如需原速播放,按各序列真实帧率重新编码 |
| 编码 | PNG:`cv2.imencode('.png') + tofile`(中文路径安全);mp4:`mp4v` fourcc,白底画面压缩率高,两个全序列 mp4 合计仅 ~35 MB |

**帧范围口径注意:** id_switch_report §4 曾概括"MOT17 帧范围 301-600(val_half)",该数值仅对 V001 等序列成立;本报告涉及序列一律以 track txt 实际范围为准——V013 的评测段实际为 **328-654**(其 gt.txt 亦为 328-654,双口径相互印证)。

## 3. 对比度分析:为什么加黑描边

**现象:** 黄金角着色(HSV S=V=255)下的纯蓝/蓝紫色框(如 V013 的 id732、V019 的 id948,亮度 225.9)与纯白背景的**亮度差仅 29.1**,在白布上几乎不可见。

**原因:** 高饱和 ≠ 与白底可分。白底对比看的是亮度差(Rec.601 亮度 `Y = 0.114B + 0.587G + 0.299R`,BGR 顺序);纯蓝、黄、青等"单通道/双通道满值"颜色在 255 底上只剩一个维度的差异。

**实测数据(两序列各自 13~14 个 ID 的颜色):**

| 序列 | 最低亮度差 | 最差 ID(亮度差) |
|------|-----------|----------------|
| MOT17 V013 | 29.1 | id732=29.1、id749=43.7、id753=46.7、id719=59.6、id757=72.4 |
| SportsMOT V019 | 29.1 | id948=29.1、id965=43.7、id969=46.7、id982=53.7、id952=54.5 |

**最终方案:** 所有白布图启用黑描边(`--outline`):先画 `line_w+2` 黑色粗线,再画 `line_w` 彩色线,黑边包裹彩线,任何颜色在白底上保持可读,同时 ID 数字仍为彩色(黑底标签条内彩色数字不受影响)。程序化验证确认每个抽样框的描边带内黑像素与彩像素均足量(见 §6)。

## 4. 例子一:MOT17 V013(MOT17-10-DPM,街道场景)

**全序列:** 帧 328-654(327 帧,该序列 val_half 评测段),1920×1080,`canvas/V013/` + `canvas_videos/V013.mp4`。

白布视图下能看出:全部检测框从画面中出现到离开的**几何轨迹**一目了然——人物框沿街道方向连续移动,尺寸随远近变化,框数(拥挤度)随帧波动;数字 ID 恒定同色,可逐框追踪"哪个颜色走到哪里"。

**事件窗口 f330-360(对应步骤 6 switch 例 1,事件帧 f345):** `canvas/examples/V013/`。f345 处可看到 gt31 身上的框从 tracker 735 的颜色**瞬间换成 737 的颜色**,而旧 735 的颜色仍在画面其他位置移动——"目标换色"事件在白布上比原图上更突出,因为没有背景干扰注意力。窗口前后帧呈现 ID 交换前后双方各自轨迹的延续。

## 5. 例子二:SportsMOT V019(篮球 v_2j7kLB-vEEk_c009)

**全序列:** 帧 1-1825(1,825 帧,全帧),1280×720,`canvas/V019/` + `canvas_videos/V019.mp4`。

白布视图下能看出:10 名运动员快速折返跑动,框的位置变化形成明显的**往复轨迹线条感**;空帧与拥挤帧交替的节奏清晰;同色球衣的运动员在无背景白布上只能靠**框色(ID)区分**,更直观地暴露"颜色即身份"的跟踪逻辑。

**事件窗口 f266-296(对应步骤 6 switch 例 1,事件帧 f281):** `canvas/examples/V019/`。f281 处可见目标 9 的框从 tracker 951 换色为 949,旧 951 的框仍在其左侧跟踪另一名运动员——两名快速跑动的运动员之间完成一次 ID 交换,白布版中"两条轨迹交叉后颜色互换"的形态非常直观。
