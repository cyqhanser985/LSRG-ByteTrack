# LSRG-ByteTrack：小型可观测性诊断实验（Go / No-Go 判据）

> ⚠️ **存档说明（2026-08-16）**：本报告数字基于 2026-08-16 事件全量重生成前的旧事件池，作方法学存档；重生成后判定不变（u1234 合并 33.5% / u2 合并 36.2%，全部 < 40% 终止线），当前数字见 `diag_exp/README.md` 与 `research/README.md` 状态速览。文中提及的 `diag_exp/recognition_summary.md` 已删除（2026-08-16），识别率明细见重生成的 `diag_exp/results/`。

在启动任何复杂的纠错动作（Reject / Resolve）之前，本实验在已冻结的 $S_r$（活跃接管）事件池上，对每个检测目标提取 **4 个计算开销极低、在线可观测的正交物理特征**，并在正常帧误报率 $FPR \le 1\% \sim 2\%$ 约束下统计各信号及其并集的召回率，据此裁决 Gate-centric DEN 技术路线是继续（演进为 `DEN-M`）还是终止（转向关联函数重构）。

**核心结论：路线判据 → 情况 B（No-Go，终止 Gate 路线）。** 以诊断中最强的两个信号——几何裕度 margin 与 2×2 交换不稳定性 Swap Instability——构成**成分级预算的固定阈值并集**（两信号各自在 FPR≤1% 预算下取最优阈值后取并，不再施加联合 FPR 约束，故各信号参数不会被整体预算互相牵制）：召回率为 **22.9% / 37.0% / 39.3%**（MOT17 / MOT20 / SportsMOT，合并 35.7%，并集 FPR 1.23%），全部低于 40% 的终止线；放宽至成分级 FPR≤2% 时合并 41.6%（并集 FPR 2.29%），越过 40% 线但仍距 50%–60% 继续线存在结构性差距。Swap Instability（合并 TPR 31.7% @FPR≤1%，AUC 0.84）是比 margin（24.5%）更强的单一信号，二者互补（并集增益 +11.2pp），但两信号相加也远不足以支撑 Gate 路线。

## 一、 实验协议

### 1) 样本口径（与 V8 / analysis.py 完全一致）

*   **正样本**：冻结 switch 事件（S_c 1,841 / S_r 1,921 / S_h 994，合计 4,756；仅 1 个无 F 帧输出框——SportsMOT 的 S_c 事件，检测级门控结构性无法评估）。S_r 行与 V8 协议逐点一致（MOT17 249 / MOT20 962 / SportsMOT 710，全部有框）。
*   **负样本**：C 组（非事件帧全部检测，含无 F−1 输出的帧——与 `analysis.py` 的 C 组人口定义一致），MOT17 144,891 / MOT20 920,064 / SportsMOT 578,406（合计 1,643,361，与冻结 summary 完全吻合）。
*   **共享资格条件（Eligibility）**：$E = top1 \ge 0.2 \wedge top2 \ge 0.2$（沿用几何门控语义，所有信号的触发均以 $E$ 为前置，保证并集口径自洽）。
*   **指标**：$TPR@FPR \le 1\%$（主口径）与 $TPR@FPR \le 2\%$（敏感性）；阈值按数据集分别搜索。并集分两种模式：① **u2（主口径）**——margin 与 swap 两信号各自在成分级 FPR≤1% 预算下取最优阈值（`best_trigger`），随后以固定阈值直接取并，**不施加联合 FPR 约束**（并集 FPR 如实报告，通常为两成分 FPR 之并集，约 1.1–1.3%）；② **u1234（对照）**——四信号联合网格搜索（每特征候选阈值 = 负样本分位数 + 显式"关闭"档）在整体 FPR 预算内最大化 $TPR$。
*   **SANITY（硬断言，已通过）**：① $S_r$ 事件计数与冻结分类一致；② 重算的 top1/top2/margin/cos_theta/v_obs_norm 与冻结 `gate_feasibility_events.csv` 逐值一致（同一代码路径，容差 5e-5 = 冻结 CSV 的 4 位小数舍入噪声，实测最大偏差 4.97e-5、均值 ~0，无系统偏差）。

### 2) 四个正交特征（全部在线可观测、因果：仅用 F−1/F−2 输出 + F 帧检测）

| # | 特征 | 定义 | 触发方向 |
|---|---|---|---|
| 1 | **Margin** | $m = top1 - top2$（对 F−1 活跃 track 恒速外推预测框的 IoU 竞争结构） | 低（$m < \varepsilon$） |
| 2 | **Motion Surprise** | $\cos\theta = \cos\big(\angle(v_{hist}, v_{obs})\big)$，$v_{hist}=F{-}1{\to}F{-}2$、$v_{obs}=F{\to}F{-}1$ 中心位移；另取归一化中心残差 $v_{obs\_norm} = \|d_t - x_{t-1}\| / \text{diag}$ 作敏感性 | 低（$\cos$）／高（$v_{obs\_norm}$） |
| 3 | **Occlusion** | $Oc_i = \max_j \frac{\|B_i \cap B_j\|}{\|B_i\|}$（同帧检测自交比 IoF，向量化） | 高 |
| 4 | **Swap Instability** | 对局部竞争对（$T_1$=top1 track，$T_2$=top2 track，$D_2$=$T_2$ 的"自有"检测，即当前分配下 $T_2$ 的匹配检测）：$\Delta C_{swap} = (c_{12} + c_{21}) - (c_{11} + c_{22})$，$c_{11}=top1,\ c_{12}=top2,\ c_{21}=IoU(D_2,T_1),\ c_{22}=IoU(D_2,T_2)$；$\Delta C > 0$ 表示交换分配更便宜 → 当前 top1 分配不稳定 | 高 |

> 注：Swap 的 $D_2$ 按"当前分配（$D_1{\to}T_1, D_2{\to}T_2$）"的自然读法取 $T_2$ 的自有检测（变体 B）；变体 A（$D_2$ = $T_1$ 的自有检测）作为敏感性记录于 `diag_roc_summary.csv`（合并 AUC 0.846 vs 0.844，性能相近）。

## 二、 四特征诊断结果（$TPR@FPR \le 1\%$，主口径）

![四特征 ROC 曲线（FPR 0–5% 放大区，合并 + 三数据集面板）](results/diag_roc.png)

| 特征 | MOT17 | MOT20 | SportsMOT | 合并 | 合并 AUC |
|---|:---:|:---:|:---:|:---:|:---:|
| 1. Margin（几何门控） | **18.1%** | 24.0% | 27.3% | 24.5% | 0.838 |
| 2. Motion Surprise（$v_{obs\_norm}$） | 4.8% | 19.3% | 17.2% | 14.7% | 0.773 |
| 2'. Motion Surprise（$\cos\theta$） | 4.8% | 2.3% | 4.6% | 2.2% | 0.586 |
| 3. Occlusion（IoF） | 6.0% | 7.1% | 3.9% | 6.1% | 0.627 |
| 4. Swap Instability（$\Delta C$，变体 B） | 18.1% | **33.1%** | **35.6%** | **31.7%** | **0.844** |

*   正样本池 = 全部有框 $S_r$ 事件（未定义特征按不触发计），故各特征 TPR 可直接比较；AUC 在"eligible 且特征可定义"子池上计算（纯信号判别力，与 V8 口径一致）。
*   **Margin**：离线 $TPR@1\%$ = 18.1% / 24.0% / 27.3%，与 day1 冻结基线（ε=0.25 档：18.07% / 24.01% / 27.32%）逐点吻合，协议自洽。
*   **Motion Surprise**：$\cos\theta$ 几乎无判别力（AUC 0.59，合并 TPR 仅 2.2%）——再次确认 day2 的 KMC 否定结论（$S_r$ 接管方运动方向正常，中位 0.80–0.90 vs 正常 0.88–0.98）；$v_{obs\_norm}$ 有中等判别力（AUC 0.77，TPR 14.7%）但被正常帧的运动拖尾压制，1% 预算下 TPR 低。
*   **Occlusion**：MOT17/MOT20 有判别力（事件检测 IoF 中位 0.855/0.659 vs 正常 0.589/0.531），但 **SportsMOT 无判别力**（AUC 0.497，中位 0.552 vs 0.524 几乎重叠）——高速稀疏场景目标相互遮挡少，"被遮挡→定位失真"机理不成立。
*   **Swap Instability（新发现）**：三数据集一致的强判别信号——$S_r$ 事件 $\Delta C$ 中位 −0.66~−0.89 vs 正常 −1.16~−1.22（事件帧交换分配比正常帧"便宜"约 0.3–0.5，即分配犹豫更强），AUC 0.73–0.86，且 100% 可定义（eligible 检测恒有 top2 与 $D_2$）。**比 margin 更强的单一门控信号**（合并 31.7% vs 24.5%）。

## 四、 并集分解：信号互补性分析

合并口径、并集最优点（margin≤0.25, vobs≥0.20, oc 关, dcb≥−0.46）下的逐事件覆盖分解：

| 事件覆盖组合 | 数量 | 占比 |
|---|---|---|
| 全部信号均未命中（含不满足资格） | 1,235 | **64.3%** |
| margin 命中（其余未中） | 77 | 4.0% |
| swap 命中（其余未中） | 216 | 11.2% |
| **margin ∧ swap 同时命中** | 393 | 20.5% |
| **并集合计捕获** | **686** | **35.7%** |

*   **margin 与 swap 明显互补**：margin-only 77 条 + swap-only 216 条 + 双命中 393 条——swap 在 margin 之外新增 ~11.2pp（35.7% − 24.5%），swap 是并集增益的主要来源（swap-only 216 条 > margin-only 77 条）。
*   **双信号重叠显著**：393 条双命中占捕获的 57%——两个信号在同一类物理情境（两目标交叉、检测框重叠、分配犹豫）上齐响，而非覆盖完全不同的失效子类。真正互斥的失效子类（如"自信而错"型：margin 大、swap 也稳定）对两个信号均不可见。
*   **结构性盲区**：64.3% 的 $S_r$ 事件在成分级 1% FPR 预算下对 margin 与 swap 均不可见——与 day1"confident-but-wrong"瓶颈（margin 中位 0.406）同源：大部分错误交换发生时，几何、运动、遮挡、交换四类观测**全部正常**。

## 五、 Go / No-Go 判定（路线决策）

| 判据 | 阈值 | 实测（并集 1∪2∪3∪4） | 判定 |
|---|---|---|---|
| 情况 A（继续 Gate 路线 → `DEN-M`） | 并集召回率 ≥ 50%–60% 且 FPR ≤ 1%–2% | S_r 合并 35.7% @1%成分 / 41.6% @2%成分；全部 switch 合并仅 23.5% @1%成分 / 27.1% @2%成分 | ❌ 未达到 |
| 情况 B（终止 Gate 路线 → 关联函数重构） | 融合信号后并集仍 < 40% | S_r：成分级 FPR≤1% 时三数据集全部 < 40%（22.9 / 37.0 / 39.3）；全部 switch：23.5%（合并） | ✅ **成立** |

**裁决：情况 B — 尽早证伪 Gate-centric DEN 路线。** 即使让最强两信号（margin + Swap）各自在成分级 FPR≤1% 预算下取最优阈值并取并，$S_r$ 事件的召回率仍 < 40%（三数据集 22.9% / 37.0% / 39.3%，合并 35.7%），全部 switch 事件仅 23.5%——距 50–60% 的继续线存在结构性差距（仅成分级 FPR≤2% 时合并 41.6% 越过 40% 线、SportsMOT 39.3% 贴线，仍差 ~10pp；仅 MOT20 拥挤场景在 swap 变体 A + FPR≤2% 下个别类别达到 50–56%）。诊断结论与 day1 的 "confident-but-wrong" 瓶颈完全自洽：**错误关联发生前不存在足够的因果可观测信号**——margin 与 swap 两观测在 64.3% 的 $S_r$ 事件（及约 76% 的全部 switch 事件）上全部"正常"。

**不再堆叠门控参数**（margin、σ 自适应、DEN 密度、运动、遮挡、交换六类信号均已验证；运动与遮挡单信号 TPR@1% 仅 14.7% / 6.1% 且与双信号并集高度重叠，边际贡献有限，故主口径收敛于 margin ∪ swap 双信号固定并集，覆盖饱和于 ~36% @1%成分）。研究重心转向**关联函数本身的改进**：

1. **观测中心运动补偿（OC-SORT 式）**：day2 已观察到在线 top1/margin 系统性偏紧（原始框抖动）；恒速 KF 预测在高速场景（SportsMOT）位移偏差最大（top1 中位差 −0.109）。在关联代价中引入观测中心的运动补偿（观测轨迹方向对齐）可直接改善"自信而错"型错误的代价结构——这正是 Swap 信号揭示的痛点（错误分配的代价优势来自预测框偏离真实目标）。
2. **搜索空间自适应（C-BIoU 式）**：用观测间的相似度修正候选搜索空间，缓解"交叉瞬间的 2×2 冲突"（本实验确认 $S_r$ 事件帧 swap 分配比正常帧便宜 0.3–0.5，冲突结构真实存在）。
3. **Swap Instability 作为廉价诊断/消融指标保留**：不继续做门控，但作为关联函数改进效果的离线诊断信号（$\Delta C$ 事件-正常分离度 AUC 0.84 可作为改进前后的敏感性指标）。
4. 可选保留：$S_h$ 通路（KF σ 增长信号）不受本裁决影响，与 Gate 路线独立。
