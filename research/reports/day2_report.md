# LSRG-ByteTrack：从离线筛选到在线插桩

> 数字口径：2026-08-16 按清洗后 GT 重生成事件池全量更新（离线数字按新事件池重算，在线数字按同轮次日志重算；零行为变化表按清洗后 GT 重评）。结论方向不变。

第一天的验证将原设计收敛至以活跃接管 $S_r$ 为纠错对象的最小闭环，并确立了几何门控（V7）作为风险分流的计算入口：以恒速外推预测框的 top1/top2 IoU 竞争结构作为触发代理，正常帧误触发率低于 0.75%，事件浓度富集 33–55 倍。然而，该门控存在原理性瓶颈——$S_r$ 事件发生时 margin 的中位数仍有 0.405（"confident-but-wrong"），导致覆盖率在 $\varepsilon=0.25$ 处封顶于 24.75%。

第二天的核心问题是：**几何裕度之外，是否存在可利用的候选风险信号？以及离线验证的增益能否在线复现？** 围绕这两个问题，本日完成了两阶段验证：

1. **候选机制的离线筛选（V8）**：对三个候选信号——运动一致性（KMC）、KF 协方差自适应裕度、局域密度（DEN）——在 FPR≤1% 预算下进行机制级验证（绝对覆盖率 + 相对固定 ε 基线的机制增量）。
2. **DEN 在线插桩（alert 模式）**：将唯一获得支持的 DEN 机制以"仅检测、不改关联"的方式插入 ByteTrack 跟踪管线，在三数据集（MOT17 / MOT20 / SportsMOT）全量统计在线触发率、事件命中率、特征对齐与运行开销。

核心结果：**KMC 与 KF 自适应机制在机制级被否定，DEN 局域密度是唯一值得在线插桩的信号**——被 V3 否定的全局拥挤度在 ego-centric 局部化后"复活"；在线插桩管线成立（零行为变化、N 近似无偏、快照逐帧一致率 100%），MOT17/MOT20 存在 FPR 预算内点（$\varepsilon_0=0.15, \gamma=1.25$ → 0.75–0.81%），但 SportsMOT 在线门控最"热"（网格内最低 FPR 1.37%），且 $S_r$ box 级命中率呈数据集方向差异——"在线复现离线增益"仅在 MOT20/SportsMOT 上量级相当，在 MOT17 上方向相反。

本文总结了从候选机制离线筛选、在线插桩验证到口径偏差归因的完整论证过程。

## 一、 候选机制的离线筛选：V8 三机制验证

几何门控（V7）已证明"几何裕度"是高信噪比的风险代理，但 margin 瓶颈将覆盖率封顶在 24.75%。为突破该瓶颈，本节在同样的样本口径下对三个候选信号做机制级验证。

### 1) 验证协议

*   **正样本**：$S_r$ 事件帧匹配对（接管方 tid 与其 F 帧检测框，1,899 条，gap 恒 = 1）。
*   **负样本**：非事件帧的全部检测（与 V7 C 组同口径）。
*   **指标**：FPR≤1% 预算下的 TPR（绝对覆盖率）＋ 机制增量（相对固定 ε 基线）。**口径注意：覆盖率可能高而机制本身增益 ≈ 0**——判定必须分开报告。

### 2) 思路一：运动一致性门控（KMC）—— ❌ NOT SUPPORTED

特征基于"错误交换常伴随运动突变"的假设：$\cos\theta$（$v_{\text{hist}} = F{-}1 {\to} F{-}2$ 与 $v_{\text{obs}} = F {\to} F{-}1$ 中心位移夹角余弦）、$r_v$（速度尺度比 max/min）、$v_{\text{obs\_norm}}$（表观位移/框对角线）。触发 = 几何 ∨ ($\cos\theta < thr \wedge top1 \ge 0.2$) ∨ ($r_v > thr \wedge top1 \ge 0.2$)。

*   三数据集在 FPR≤1% 预算下 TPR 全部 ≈ 0（网格最小 FPR 也在 4–16%）。
*   **关键否定**：$S_r$ 接管方的运动**并不异常**——$\cos\theta$ 中位 0.73–0.90（方向一致）、$r_v$ 中位 1.57–1.90。"confident-but-wrong 伴随运动突变"的假设被数据否定；掉头（$\cos\theta < 0$）是合法运动，且贡献了主要 FPR。
*   单特征最强者为 $v_{\text{obs\_norm}}$（MOT20 AUC 0.76），但在 1% FPR 处 TPR 仅 0–19%。

### 3) 思路二：KF 协方差自适应裕度 —— ❌ 机制级 NOT SUPPORTED

利用卡尔曼预测协方差调整每检测的触发阈值：$\sigma = \sqrt{\mathrm{Tr}(P_{xy})}$（KF 重放：协方差演化与测量无关，重放 σ ≈ 在线 σ），$\varepsilon_i = \varepsilon_0 \cdot (1 + \alpha \cdot \hat\sigma_i)$，$\hat\sigma = \sigma / h_{\text{state}}$。

| 数据集 | $S_r$ σ̂ 中位 | 正常帧 σ̂ 中位 | Spearman(margin, σ) | 机制增益 |
|---|---|---|---|---|
| MOT17 | 0.0576 | 0.0575 | 0.036 | +0.00pp |
| MOT20 | 0.0577 | 0.0575 | 0.029 | +0.64pp |
| SportsMOT | 0.0584 | 0.0575 | 0.060 | +0.99pp |

*   $S_r$ 的 σ̂ 与正常帧**完全重叠**（gap=1 → 恒稳态），margin 与 σ 无相关——协方差自适应对 $S_r$ 无判别力；绝对覆盖率 18–28% 只是几何 ε 扫描的反映。
*   σ 信号的真正主战场是 $S_h$（lost 期 σ 增长），留作冷启动/历史激活通路。

### 4) 思路三：局域密度门控（DEN）—— ✅ 唯一值得在线插桩

$N_{\text{neighbor}}(i)$ = F−1 帧与 track $i$ 重叠的活跃 track 数（自 IoU 矩阵）；$\varepsilon_i = \varepsilon_0 \cdot \gamma(N)$，$\gamma(0) = 1$、$\gamma(\ge 1) > 1$。

| 数据集 | $S_r$ N 中位 | 正常 N 中位 | $S_r$ N=0 占比 | 正常 N=0 占比 | γ 机制增益 |
|---|---|---|---|---|---|
| MOT17 | 2.0 | 1.0 | 2.4% | 26.1% | +3.66pp |
| MOT20 | 5.0 | 4.0 | 1.3% | 4.8% | +6.79pp |
| SportsMOT | 2.0 | 1.0 | **11.0%** | **49.9%** | +6.20pp |

*   SportsMOT 最优点为 eps0=0.20、γ=1.25 → TPR **27.3%** @FPR≤1%（γ=1.0 基线 21.1%）。
*   **V3 否定的全局拥挤度在 ego-centric 局部化后复活**——$S_r$ 事件显著更"拥挤"。
*   判别力随 domain 递增（MOT17 < MOT20 < SportsMOT），与"高速稀疏场景竞争信号最强"一致。

### 5) 汇总判定

![V8 三候选机制 ROC 曲线：FPR≤1% 预算下 KMC / KF 自适应 / DEN 的 TPR（面板为合并与三数据集，analysis.py 生成）](taxonomy/gate_feasibility_roc.png)

| 机制 | MOT17 | MOT20 | SportsMOT | 建议 |
|---|---|---|---|---|
| KMC 运动一致性 | NOT SUPPORTED | NOT SUPPORTED | NOT SUPPORTED | 放弃 |
| KF 自适应裕度 | 机制 NOT SUPPORTED | 机制 NOT SUPPORTED | 机制 NOT SUPPORTED | 放弃（σ 留给 S_h 通路） |
| DEN 局域密度 | PARTIAL (+3.7pp) | PARTIAL (+6.8pp) | SUPPORTED (+6.2pp) | **在线插桩** |

**裁决**：DEN 为唯一获得支持的机制，进入在线插桩阶段。

## 二、 DEN 在线插桩：检测模块（alert 模式）的三数据集全量验证

离线筛选确认 DEN 后，将其插入 ByteTrack 在线管线。插桩的第一阶段只做"检测"（alert 模式，不改关联行为），统计在线触发率并与 V8 离线验证表对齐；纠错动作（reject / Resolve 路由）留待本阶段结论确认后的下一轮。

### 1) 插桩设计与防泄露

| 项 | 内容 |
|---|---|
| 代码 | `yolox/tracker/den_gate.py`（新，纯函数）+ `byte_tracker.py`（L207-209 门控特征块 + 帧末快照 + `dump_den_log`）+ `mot_evaluator.py`（dump 钩子）+ `tools/track_v001.py`（CLI） |
| 开关 | `--den-gate`（默认关，基线路径零变化）；`--den-eps0 0.20`、`--den-gamma 1.25` |
| 动作 | **alert（仅记录）**——不修改关联代价矩阵 |
| 备份 | 改前文件在 `research/code/backup/`（SHA256SUMS.txt 已核对） |

```
检测 D@F + F−1 快照(输出框) + KF 预测框(恒速)
        │
        ├── N      = 与 track i 重叠的 F−1 活跃 track 数（自 IoU 矩阵）
        ├── top1/2 = 未融合 dists 上每检测的 IoU 候选
        │
        └── Trigger ⇔ top1 ≥ 0.2 ∧ top2 ≥ 0.2 ∧ margin < ε0 · γ(N)
                        │
                        ▼
             alert（记录候选行 + 检测框 + 帧摘要，不改关联）
```

**防泄露纪律**：门控输入仅 F−1 快照（输出框）＋ 当前检测 ＋ KF 预测框；**帧号资格** `cur_frame == snap_frame + 1`（mot_evaluator 跳帧时不误用旧快照）。

### 3) 在线触发率与事件命中（冒烟 → 全量）

冒烟（@ε0=0.20, γ=1.25）：MOT17 V002 FPR 代理 2.97%；SportsMOT V043 4.22%——**在线 FPR 代理约为离线预算的 3–6 倍**，且 SportsMOT（高速稀疏）反而高于 MOT17，与离线"判别力随 domain 递增"趋势相反（归因见 §三）。V002 帧级事件命中：$S_r$ 56.8%（n=37）/ $S_c$ 76.9%（n=13）/ $S_h$ 80.0%（n=15）。

全量（锚点 ε0=0.20, γ=1.25）：

| 数据集 | 序列 / 帧 / 候选行 | FPR 代理 | $S_r$ box 级命中 | 快照一致率 | 开销（gate / 快照） |
|---|---|---|---|---|---|
| MOT17 | 21 / 7,977 / 56,205 | 1.56% | 14.3%（246 事件） | 100%（7,956 帧） | 0.66 / 0.84 ms/帧 |
| MOT20 | 4 / 8,931 / 744,688 | 1.55% | 39.2%（943 事件） | 100%（8,927 帧） | 2.08 / 4.17 ms/帧 |

*   开销：MOT20 密集场景最重（gate+快照 ≈ 6.3 ms/帧，约 12% 跟踪耗时；跟踪平均 52.9 ms/帧）；MOT17/SportsMOT 合计 < 1.5 ms/帧。
*   $S_c$/$S_h$ 的 box 级命中（如 MOT20 45.6% / 43.7%）是"接管检测被门控触发"的度量，不构成 DEN 选择性证据（离线 DEN 正样本仅 $S_r$）；$S_c$ 命中率的场景差异（MOT20 45.6% vs SportsMOT 5.9%）反映场景密度而非门控行为差异。

### 4) ε0×γ 后验网格与预算内点（MOT20 示例）

候选行日志存原始特征（top1/top2/margin/N + 检测框），网格可后验重算，无需重跑：

| ε0 | γ | FPR | $S_r$ frame/box | $S_c$ frame/box | $S_h$ frame/box |
|---|---|---|---|---|---|
| 0.15 | 1.00 | 0.58% | 68.5% / 24.1% | 66.4% / 31.3% | 69.6% / 26.6% |
| 0.15 | 1.25 | **0.81%** | 78.0% / **29.6%** | 75.7% / 38.6% | 78.4% / 32.7% |
| 0.20 | 1.00 | 0.91% | 80.2% / 31.0% | 78.8% / 39.4% | 82.4% / 34.2% |
| 0.20 | 1.25 | 1.55% | 90.1% / 39.2% | 86.9% / 45.6% | 91.2% / 43.7% |
| 0.20 | 1.50 | 2.89% | 96.3% / 47.7% | 94.2% / 50.6% | 96.0% / 53.3% |

*   **预算内点**：MOT17/MOT20 取 (0.15, 1.25) → FPR 0.75–0.81%，对应 $S_r$ box 级命中 10.4% / 29.6%；**SportsMOT 网格内最低 1.37%**（0.15, 1.0）→ box 级 27.5%（≈ 离线 27.3%）。

## 三、 在线/离线口径偏差归因

### 已验证（有数据支撑）

1.  **特征偏移（原始检测框 vs KF 滤波输出框）**：事件帧特征对齐显示在线 top1/margin 系统性偏低（见 §二.4）——原始框抖动使同 (ε0, γ) 下触发更频繁，解释了 FPR 代理（1.5%）略高于离线 1% 预算；收紧至 (0.15, 1.25) 即可回到预算内（0.75–0.81%）。
2.  **N 近似成立**：top1 track 的 N 与接管方自身 F−1 邻居数中位差 0、P90 ≤ 1——在线"top1 track N"近似无实质偏差。
3.  **快照口径一致**：与同运行 track_results 逐帧一致率 100%（含 vertical/min_area 过滤与 0.1 舍入复刻）。

### 未完全解释（假设，待进一步实验）

*   **$S_r$ box 级命中的数据集方向差异**：MOT20 在线 29.6% > 离线 24.5%，MOT17 在线 10.4% < 离线 18.3%。候选解释（Hypothesis，非结论）：① MOT17 场景每帧 track 少，候选行 top2≥0.2 的门槛使部分事件检测不入候选池（原始框 top2 抖动跌破 0.2）；② MOT20 拥挤场景原始框 margin 更小 → 触发更容易。可验证：对 MOT17 未命中事件检查其候选资格（top2 分布）。
*   **$S_h$ box 级命中高于 $S_r$（MOT17 24.1% vs 14.3%）**：$S_h$ 接管检测（重新激活后）与现存 track 预测框重叠小 margin → 易触发。DEN 从未在 $S_h$ 上做离线验证，此现象不构成 DEN 失效证据，但提示 $S_h$ 场景需要专属口径（与 $S_h$ 通路规划一致）。

## 四、 结论与后续工作

1.  **三机制离线筛选收敛**：KMC（$S_r$ 接管方运动不异常）与 KF 自适应（σ̂ 恒稳态、margin 与 σ 无相关）在机制级被否定；**DEN 局域密度是唯一获得支持的信号**（γ 机制增益 +3.7 ~ +6.8pp）——被 V3 否定的全局拥挤度在 ego-centric 局部化后复活，与"速度主导"结论相容（高速稀疏场景中竞争者紧邻，竞争信号最强）。
2.  **在线检测模块成立**：alert 模式零行为变化（同轮次对比在噪声带内）、N 近似无偏（中位差 0、P90 ≤ 1）、快照逐帧一致率 100%、开销可控（MOT17/SportsMOT < 1.5 ms/帧，MOT20 ≈ 6.3 ms/帧）。
3.  **FPR 预算**：MOT17/MOT20 存在预算内点（(0.15, 1.25) → 0.75–0.81%）；**SportsMOT 网格内最低 1.37%**——高速目标原始框与 KF 预测框偏差最大（top1 中位差 −0.109），需更紧 ε0（< 0.15）或接受更高 FPR。
4.  **$S_r$ box 级命中数据集依赖**（预算点）：MOT20 29.6%（> 离线 24.5%）、SportsMOT 27.5%（≈ 离线 27.3%）、MOT17 10.4%（< 离线 18.3%）——"在线复现离线增益"在 MOT20/SportsMOT 量级相当、MOT17 方向相反（归因假设见 §三，待验证）。
5.  **下一步（修复模块）**：reject 动作（匹配前 cost 屏蔽、lap 全局重解）——触发对 (top1 track, det) 从第一阶段匹配前排除；参数以预算内点 (0.15, 1.25) 为锚（SportsMOT 单独考虑 ε0=0.10–0.15），最终按 IDS/IDF1 系统级指标定型；$S_h$ 通路预留（KF σ 在 lost 期增长，留作历史重新激活信号，本轮不启用）。
