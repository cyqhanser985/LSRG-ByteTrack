## 1. 事件定义与分类

一次 ID 切换（IDS）事件 = (seq, frame, track_id, gt_id_old → gt_id_new)，"目标换了 tracker"。基于事件帧接管方 track_id 的输出历史，四类互斥失效模式：

| 类 | 判定（na_flag） | 物理含义 |
|---|---|---|
| **S_c 冷启动接管** | `no_last_seen`（接管方此前从未输出） | 目标由新初始化的 tracklet 接手 |
| **S_r 活跃接管** | 无 `no_prev`（紧邻帧 F−1 有输出） | 活跃 tracker 间快速身份交换 |
| **S_h 历史重新激活** | 有 `no_prev`（更早帧有输出但 F−1 无） | 休眠轨迹重新激活并接手 |

**全体 4,756 条 IDS**：S_c 1,841（38.7%）/ S_r 1,921（40.4%）/ S_h 994（20.9%）。

**双视角不嵌套**：type=switch（GT 视角）与 type=reuse（tracker 视角）是同一物理现象的两个观察视角，|S∩Reuse| = 0——旧经验公式 β = R/((1−α)S) 被否定（MOT17 反解 β=1.33 > 1，不可能是概率）。

**场景参数**（α = switch 占比，π_r = 活跃接管占比）：

| 数据集 | α | π_r |
|---|---|---|
| MOT17 | 22.4% | 58.5% |
| MOT20 | 16.6% | 70.3% |
| SportsMOT | 56.3% | 63.3% |

## 2. 物理签名（三类分离性）

| 指标 | S_r | S_h |
|---|---|---|
| gap（事件帧 − 最后输出帧） | **恒 1**（100%） | 中位 6，gap>5 占 56.3% |
| IoU_last 中位 | 0.854 | 0.383 |
| dist_last P90 | **14.9 px** | **97.3 px**（约 S_r 的 6.5 倍） |

- **S_r 强局域**：接管方就在上一帧的紧邻位置——高密度区"邻居间快速身份交换"，工程上最可及（gap=1、空间最局域、复杂度最低）。
- **S_h 长尾漂移**：休眠多帧后远距离重新出现——与 S_r 显著分离，证实两类对应不同物理机理。
- **S_c 结构性盲区**：接管方无历史（按定义）；380 条（20.6%）事件中旧 tracker 在事件帧仍在场，但 IoU_swap 中位仅 0.235、中心距中位 28.8 px——旧轨迹通常在场但不重合，存在可挽回空间。

## 3. 冷启动可挽回上限

对 1,841 条 S_c 事件，检查事件帧检测框与其 GT 目标旧轨迹的可达性（恒速外推旧 tracker 最后框到事件帧，IoU≥0.3 或中心距≤0.5·对角线，并集口径）：

- **在场未认领 380 条（20.6%）** + 消亡 1,461
- **Recoverability_S_c(L) = 43.1%（L=30）→ 44.4%（L=60 后饱和）**；严格 IoU≥0.3 口径 29.7%→30.0%
- 曲线饱和快：瓶颈是**可达性而非消亡间隔**（恒速外推对长间隔失效，尤其 SportsMOT 高速）
- 数据集差异：MOT17 85.4%（多为在场未认领）、MOT20 60.3–66.9%、SportsMOT 36.3–36.7%

## 4. 研究含义

- S_r 是唯一纠错对象（占比最高 40.4%、gap=1、空间最局域、工程复杂度最低）——**最小定向纠错闭环**：分类诊断 → 轻量风险判断（是否 S_r 风险）→ S_r 局部纠错 / 保持 ByteTrack。
- S_c 可挽回上限 44.4% 且结构性地在场不重合——冷启动纠错收益有限，优先级低于 S_r。
- 门控检测的目标类为 S_r；特征纪律：gap / IoU_last / dist_last 是**离线诊断指标**，不得作为在线门控输入（在线只能用因果特征）。
