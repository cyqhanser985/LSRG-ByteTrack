## 四、Day 3 可观测性诊断实验（2026-08-10，Go/No-Go 判据）

### 已完成：四特征诊断 + 路线裁决（情况 B，终止 Gate 路线）

- **背景**：`研究方向.md` 要求在冻结 S_r 事件池上验证 4 个廉价正交门控信号（Margin / Motion Surprise / Occlusion / Swap Instability）的联合召回率，裁决 Gate 路线去留（并集 ≥50–60% → 继续演进 DEN-M；<40% → 转向关联函数重构）。
- **代码**：`diag_exp/run_diag.py`（新，独立工作区；通过 `import analysis` 复用 code/ 全部工具函数；纯 numpy 向量化，全量 ~70s）。SANITY 硬断言：S_r 计数（249/962/710）+ 逐事件特征与冻结 `gate_feasibility_events.csv` 逐值一致（容差 5e-5 = 冻结 4 位小数舍入噪声）。
- **产物**（`diag_exp/results/`）：`diag_features_events.csv`（**4,756 事件 × 8 特征**，全类别 + no_box 标记）、`diag_roc_summary.csv`（类别 × 6 特征 × TPR@1%/2%/AUC）、`diag_union_summary.csv`（类别 × u12/u1234/u1234a + 最优点阈值）、`diag_roc.png`；另 `diag_exp/recognition_summary.md`（全类别识别率汇报表）。
- **结论**（详见 `reports/day3_report.md`，全类别识别率见 `diag_exp/recognition_summary.md`）：
  - 四特征并集 TPR@FPR≤1% = MOT17 24.1% / MOT20 37.0% / SportsMOT 36.2%（合并 33.6%）——**全部 < 40% 终止线，判情况 B（No-Go）**；FPR≤2% 时合并 40.6%（MOT20/SportsMOT 43–45%）仍距 50–60% 继续线 ~10pp。
  - 新发现：**Swap Instability 是最强单一信号**（合并 TPR 31.7% @1%、AUC 0.844）> margin（24.5%）；margin∧swap 互补 +9.1pp，其余信号边际 ≈0（motion cos 再次否定；occlusion 在 SportsMOT 无效，AUC 0.50）。
  - **66.4% 的 S_r 事件对全部廉价信号不可见**——"错误关联前存在足够因果可观测信号"的假设被证伪（与 day1 "confident-but-wrong" 瓶颈同源）。
  - **全类别扩展**：并集识别率（FPR≤1%）S_c 9.5%（SportsMOT 2.6%，合格事件仅 12%、结构性盲视）/ S_h 25.7% / S_r 33.6% / **全部 switch 22.6%**（FPR≤2% 时 26.8%）；MOT20 拥挤场景例外（S_c 44.9% / S_h 42.9%）；Motion Surprise 对 S_c/S_h 结构上不可计算（无 F−1 历史）；Swap 变体 A 在 S_c/S_h 上更强（S_h 29.7% vs 8.1%），重建并集后全部 switch 22.6%→24.0%。
- **裁决动作**：不再堆叠门控参数（margin/σ/DEN/运动/遮挡/交换六类信号覆盖饱和 ~34% @1%），**转向关联函数重构**：① OC-SORT 观测中心运动补偿（高速场景预测偏差最大）；② C-BIoU 搜索空间自适应；③ Swap ΔC 保留为关联函数改进的离线诊断指标（AUC 0.84 敏感性）。

### 下一步（路线转向后）

1. **关联函数重构方向（OC-SORT / C-BIoU）**：先在冻结数据上离线验证"运动补偿后的代价结构是否消除 S_r 的代价优势"（swap ΔC 事件-正常分离度作为敏感性指标）
2. 可选：S_h 通路（KF σ 增长信号）与 Gate 路线独立，不受本裁决影响
